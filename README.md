# Actividad 2: Juego Snake 

## Contenido

Este repositorio cuenta con el código en Python del juego **Snake**, utilizando las librerías `random`, `turtle` y `freegames`.

Se agregaron 2 cambios respecto al código original:

- Volviendo la posición de la comida errática.
- Cambiando aleatoriamente el color de la serpiente.

## Objetivo

Modificar el repositorio utilizando el control de versiones de **Git** y funciones de **GitHub** como *fork* y *pull requests*.
